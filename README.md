# Hitelesitő+

\------------------------------- HU ------------------------------------ 

> Többfaktoros hitelesítés (TOTP, e-mail kód, Passkey/WebAuthn, biztonsági mentési kódok) szerepkör alapú kötelezővé tételi lehetőséggel, bejelentkezés utáni átirányításos hitelesítő felülettel és opcionális brute force védelemmel.

\------------------------------- EN ------------------------------------ 

> Multi-factor authentication (TOTP, email code, Passkey/WebAuthn, backup codes) with role-based enforcement, post-login redirect authentication interface, and optional brute force protection.

### Telepítési folyamat

- Töltsd le ZIP file-ként a csomagot vagy a Release-be a ZIP file tartalmát
- Wordpress weboldalon menj a "Bővítmények" &gt; "Bövítmény hozzáadása" majd a "Bővítmény feltöltése" felületre és tallózd ki a letöltött zip file-t.
